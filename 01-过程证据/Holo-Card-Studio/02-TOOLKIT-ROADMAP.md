# HoloLab Studio · 增强工具箱清单（TOOLKIT ROADMAP）

> 本文档盘点可用工具（AI 助手内置技能/插件/工具），筛选出能增强 HoloLab
> Studio 的项目，按使用环节分组并标注优先级。作为后续迭代的规划依据。
> 更新日期：2026-09-29

## 盘点方法

从全部可用技能中，按「对 HoloLab Studio 的价值」筛选：

- **保留**：与项目相关的工具；
- **剔除**：与项目无关的领域工具（见文末「已剔除领域」），避免干扰规划。

## 两层定位（重要）

所有入选工具按作用分两层，**不可混为一谈**：

- **L1 项目本体增强**：让项目的技术/功能/产品/工程本身变得更强；
- **L2 展示与传播**：提升项目的曝光与观感，**不改变项目本身**（仅"拍给人家看"）。

> 注意：L2 在申请语境里有价值（10 秒抓住招生官注意力），但它不是技术增量；
> 预算与精力应优先投在 L1。

## C. 展示与传播（L2：仅展示，不增强本体）

| 工具 | 用在项目哪个环节 | 带来什么 | 优先级 |
|---|---|---|---|
| **doubao-creative-video** + 视频生成工具 | 生成 30–60 秒项目 demo 视频 | 作品集置顶展示视频 | ★★★ 强烈推荐 |
| **byted-mediakit-\*** | 剪辑 demo 视频、字幕压制 | 成片质感 | ★★ 配合上 |
| **text_to_audio_plus / audio_to_audio_plus** | demo 视频旁白解说 | 中英双语配音 | ★★ 配合上 |
| **doubao-newmedia-writing** | 项目揭秘文章（公众号/小红书/博客） | 建立个人技术品牌 | ★ 可选 |

> **L2 → L1 的转化路径（推荐）**：视频工具可以变成产品本体功能——
> 为每张卡生成自动旋转的 3D 动态预览（展厅缩略图 hover 播放）。这样视频工具
> 就不再是"录制项目"，而是给产品新增真实交互功能，属于 L1。

## 推荐实施顺序（L1 本体增强优先于 L2 展示）

1. **展厅主视觉 + 架构信息图**（L1）：第一眼专业度 + 申请叙事清晰度
2. **卡片动态预览**（L1 转化路径）：每张卡自动旋转预览，视频工具变成产品功能
3. **项目白皮书**（作品集交付物）：给教授/招生办看的完整技术手册
4. **demo 视频**（L2 展示）：作品集置顶演示视频
5. **行业/产品/论文研究**（L2 佐证）：申请季写 PS/研究陈述时使用
