# Travel Footprint Map — 前端质感最终方案

> 审查范围：完整阅读 `frontend/src/` 下 5 个 tab 页 + 详情/表单/登录/分享页 + 全部基础组件 + shadcn 基础组件 + 设计令牌 + 10 张概念图。
> 方案立场：**不照搬概念图，以"旅行手帐"为统一气质做减法**。

---

## 〇、一句话主张

**现在的问题不是"不够好看"，而是"加太多了"——渐变加太多、阴影加太多、卡片加太多、动效加太多、颜色加太多。要做的是往回删，删到剩下一本会动的旅行手帐该有的样子。**

手帐 ≠ Dashboard：
- Dashboard：卡片整齐、数据醒目、渐变 hero、阴影浮起、每区块带图标
- 手帐：纸感、拍立得白边照片、日期邮戳、纸胶带、留白多、颜色克制、翻页有手感

## 二、最终方案（四层）

### 第 1 层：全局基础令牌（改 `index.css`，一次到位）

#### 1.1 字体
```bash
pnpm add @fontsource/noto-serif-sc
```
```css
/* index.css 顶部加 */
@import "@fontsource/noto-serif-sc/400.css";
@import "@fontsource/noto-serif-sc/700.css";

/* 改 --font-display */
--font-display: "Noto Serif SC", "Songti SC", "Playfair Display", Georgia, serif;
```
**用途**：所有页面大标题、月份大数字、Stats 英雄数字、详情页地点名。正文/按钮/标签保持系统无衬线。

#### 1.2 颜色收敛
```css
/* 主色压深（原 0.58 0.145 158 太亮） */
--primary: oklch(0.45 0.10 155);
--primary-foreground: oklch(0.98 0.01 90);

/* accent 橙压深（原 0.72 0.185 48） */
--accent: oklch(0.62 0.15 50);
--accent-foreground: oklch(0.99 0.01 90);

/* 6 个分类色色度全部从 0.16-0.18 压到 0.08-0.10 */
--scenery: oklch(0.60 0.08 155);
--food:    oklch(0.68 0.10 60);
--culture: oklch(0.58 0.10 305);
--city:    oklch(0.58 0.08 240);
--family:  oklch(0.60 0.10 15);
--outdoor: oklch(0.60 0.08 200);
```

#### 1.3 删除/修改
- **删掉 `.text-grad-vivid` 的所有使用点**（标题改 `color: var(--foreground)`）
- **删掉 `.paper-texture`**（圆点噪点肉眼无用还发灰）
- **`.card-paper` 删掉 inset 高光**，只留一层淡影：
  ```css
  .card-paper {
    box-shadow: 0 2px 8px oklch(0.4 0.03 80 / 0.06);
  }
  ```
- **统一圆角**：卡片 16px（`rounded-2xl`），输入框 10px（`rounded-[10px]`），按钮胶囊（保留），图标容器 8px。不再出现 24px 大圆角。

### 第 2 层：核心组件改造

#### 2.1 底部导航 + 中央 FAB（改 `BottomNav.tsx`，新建 `Fab.tsx`）
- 选中态：**去掉渐变圆角块**，改成图标变色 + 文字加粗 + 底部 2px 短横线指示器
- 中间插入一个 56px 橙色圆形 FAB（+号），悬浮在导航上方 16px，点击跳 `/checkin/new`
- FAB 用已有的 `.fab-float` 动画（3.2s 上下浮动 3px）

#### 2.2 空状态系统（重写 `EmptyState.tsx` + `TravelIllustration.tsx`）
- **虚线框改实线**：`border: 1px solid var(--border)`
- **`TravelIllustration` 做 4 个真正不同的场景**（不是换色）：
  - `timeline`：一本翻开的手帐 + 一支笔
  - `wishlist`：一个信封 + 一张机票
  - `stats`：一个罗盘 + 一杯咖啡
  - `me`：一个行李箱 + 一张拍立得
  - `empty`（通用）：保留现在的山+图钉
- **地图页空状态不要卡片**：直接在地图中央浮一个毛玻璃提示条

#### 2.3 卡片拍立得化（改 `CheckinCard.tsx`）
有照片时：
```jsx
<div className="bg-white p-2 pb-8 shadow-md -rotate-1">
  <img className="h-40 w-full object-cover" />
</div>
```
- 白边 + 底部留 32px（模拟写日期处）+ 轻微旋转 -1°
- 这是"手帐感"最立竿见影的一个改动

#### 2.4 邮戳真正用起来（用 `TravelDecor.tsx` 已有的 `Postmark`）
- `CheckinDetail.tsx` 日期旁边盖一个旋转 -5° 的邮戳
- `Timeline.tsx` 每个卡片右上角小邮戳

### 第 4 层：动效做减法

- **删掉所有包在区块标题外的 `<FadeIn>`**——SectionTitle 不需要入场动画
- 首屏 hero 保留 fadeUp(y:24)，列表项 stagger 从 0.1 改 0.04 紧凑入场
- tab 路由动画：Map↔其他用 `slide-fade`（横向），其他 tab 之间用 `fade`（不要都 slide-up）
- **只保留按钮和 FAB 的 `active:scale`**，删掉卡片/行/导航 tab 的 scale
- 删掉 `HoverLift` 在 CheckinCard 上的 hover y:-3（移动端无效）

## 四、和原概念图的分歧（我不照搬的地方）

1. **Stats 4 数据卡**：概念图是"图标在上+数字+标签"的标准 dashboard 卡，我改成"大宋体数字+小标签"，不要图标，更克制。
2. **Me 成就徽章**：概念图是盾牌形状（太像游戏成就），我保留邮票形状但加齿孔边 + 大小错落，更贴手帐。
3. **Wishlist 布局**：概念图是 3×2 分类网格，我不照搬——真实数据不会每个分类都有记录，硬排网格会出很多空卡。保留纵向列表，但未点亮状态从"虚线框"改成"灰拍立得占位"。
4. **底部导航**：概念图是极简图标无 FAB，我加中央橙色 FAB——"记录打卡"是这个 app 第一动作，值得一个视觉锚点。
