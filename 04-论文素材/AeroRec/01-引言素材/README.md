# 01-引言素材

> 服务章节：引言（问题定义 / 动机 / 现有方案不足）。

## 已溯源素材（2026-10-15 整理归位；事实唯一源为主仓库 `docs/`）

### 问题定义
- 曝光偏差两 classic 类型：热门度偏斜（π ∝ truth^τ）与位置偏斜（1/rank^η），`injectors.py` 两类注入器；观测点击 `y ~ Bernoulli(truth)` 仅在曝光位置产生 → 离线评估失真。
- 去偏工具箱：IPS / SNIPS / DR（`src/bias/estimators.py`，均为文献标准实现）；核心张力是**纠偏收益 vs 方差代价**，何时划算缺乏可操作判据——本文给出 ESS/N 预警判据。

### 动机（oracle 设定，本项目独有）
- 真实日志只能*估计*偏差、永远不能*测量*；本项目真实 CTR 由解析函数生成（`compute_true_ctr`）、propensity 闭式已知 → 「偏差 = 有偏观测 − 已知真值」可精确测量（`docs/bias_report.md` §1）。
- 合成数据的第二条理由：可隔离单一机制——机制 A（水平/稀疏收缩，τ=0 也存在）与机制 B（排序/曝光偏斜）的区分是本研究的核心度量设计（§2）。

### 现有方案不足 → 本文贡献点（引言末段的可用句料）
1. 曝光偏差在「召回→排序→混排」链路上的**逐级传播测量**（排序反转零交叉 τ≈2–3）；
2. 混排基础分的**二次注入**：注入符号由「信息是否已在候选集中」判别；
3. 去偏有效边界的**可落地判据**：ESS/N ≈ 0.358 阈值标定 + 无需 ground-truth 的 `ess_warning_from_log`；
4. **估计目标分离**的实测验证：naive→T_exp、SNIPS→T_pop，「IPS 换的是 estimand，不是修坏估计」；
5. 全链路**零漂移可复现工件**：CI 逐字节校验 5 个 JSON 产物（reproducibility 即贡献点）。

### 数据与基准
- 合成出行域流量（AUC 0.8019 / 相对热门 +28.5%，诚实口径：不因真实数据验证升级）；
- 迁移性验证：Criteo 1M（AUC 0.7733）、UCI Adult（0.9183）——证明模型实现可学真实信号，但非出行域；
- 去偏研究标准基准：Coat（Schnabel 2016）/ Open Bandit Dataset（ZOZO）→ Future work。

## 能支撑的论点
- 引言可用「一个反直觉结论」开场：偏差的主要危害不是估计偏高，而是**把排序搞反**；去偏成败不取决于偏差强度，取决于 π 动态范围。
