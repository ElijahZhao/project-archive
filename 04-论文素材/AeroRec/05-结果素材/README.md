## 已溯源素材（指针见 `00-索引.md` 二、四）
- **核心结果（S2 扩规模新基线，commit `c2f1567`；items=500 / requests=5000，30 种子均值±std）**：
  - 边界 `cross_ess_ratio = 0.3579`（扩规模前 0.3576，对规模稳健；阈值约 0.358 收益转负）。
  - 注入 `injection_spearman` 严格单调 0.0（w=0）→ 0.9655（w=1.0），无顶点；w=1.0 端点 L3≡truth（rel_err=0、spearman=1.0、std=0，实现自检）。
  - 传播 τ 增大 `exposure_gini` 0.0794→0.6921、`exposure_kl` 0.0100→0.9716；`L2_spearman` 0.8665→**−0.5054**（±0.01~0.03，零交叉 τ≈2–3）；`impr_min` 30.1→0.0。
- **负结果（部分撤销，重要）**：
  - 注入 `injection_spearman` 经 M2 统一 RNG 后**严格单调上升**，旧版「w=0.8 顶点 +0.8252 / w=1.0 回落 +0.7418」为**采样噪声伪影**，已撤销。`[已溯源] 1d6ab88`
  - 传播 `τ=3` 时 `L2_spearman` **转负**（−0.5054，零交叉 τ≈2–3）仍成立，且带跨种子误差棒。`[已溯源] c2f1567`
  - 高偏场景 `snips_err`（0.0651）反高于 `naive_err`（0.0024）——SNIPS 在高偏下失效。`[已溯源]`

## 能支撑的论点
- 「去偏非单调增益」「去偏器在高偏场景反劣」——直接构成 Limitations / lessons learned，反是论文贡献。
- 扩规模前后核心结论一致（0.3576→0.3579、反转仍现于 τ≈3）——可写「结论对规模稳健」。
