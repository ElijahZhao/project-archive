## 已溯源素材（指针见 `00-索引.md` 二、四）

  - 传播 `τ=2/3` 时 `L2_spearman` **转负**（−0.0516 / −0.4955）。`[已溯源]`
  - 高偏场景 `snips_err`（0.0616）反高于 `naive_err`（0.0021）——SNIPS 在高偏下失效。
