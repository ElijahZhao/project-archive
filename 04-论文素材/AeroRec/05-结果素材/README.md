## 已溯源素材（指针见 `00-索引.md` 二、四）
- **核心结果（M2 新基线，commit `1d6ab88`）**：边界 `cross_ess_ratio = 0.3576`（阈值约 0.358 收益转负）；注入 `injection_spearman` 严格单调 0.0（w=0）→ 0.8285（w=1.0），无顶点；传播 τ 增大 `exposure_gini` 0.0789→0.5898、`L2_spearman` 0.8612→**−0.3757**（零交叉 τ≈2–3）。
- **负结果（部分撤销，重要）**：
  - 注入 `injection_spearman` 经 M2 统一 RNG 后**严格单调上升**（0.0→0.1949→0.3963→0.8042→0.8285），旧版「w=0.8 顶点 +0.8252 / w=1.0 回落 +0.7418」为**采样噪声伪影**，已撤销。`[已溯源] 1d6ab88`
  - 传播 `τ=3` 时 `L2_spearman` **转负**（−0.3757，零交叉 τ≈2–3）仍成立。`[已溯源] 1d6ab88`
  - 高偏场景 `snips_err`（0.0616）反高于 `naive_err`（0.0021）——SNIPS 在高偏下失效。`[已溯源]`
