## 二、已溯源技术事实（直接可进素材包）

来源基准：主仓库 `HEAD = 5fc3933`（tag `v0.1.0` → 6fd8f28；S2 扩规模 + S3 显著性 + 历史补测 + 扩展实验 #4/#5/#6）；产物 `data/bias/*.json` 共 **7 份**（含 `*_std` 误差棒 + `significance` 检验字段）；文档 `docs/bias_report.md`（§8 扩展实验）。

### 2.1 去偏边界实验（boundary.json）· `[已溯源]`

- 配置：`n_records = 20000`，`tolerance_used = 0.001`，`n_seeds = 250`（边界多种子平均，随 requests 5000 升档），`pi_min/pi_max` 扫描 6 档（`pi_ratio` 1 → 2×10⁶）。
- **核心结论**：`cross_ess_ratio = 0.3579`（扩规模前 0.3576，**对规模稳健**）；ESS/N 降至约 **0.358** 以下时，去偏收益转负且超出噪声水平（容差 0.0010）——IPS 的方差代价超过纠偏收益。
- `naive_err` 各档恒为 `0.0024`；`snips_err` 随 `pi_ratio` 上升：0.0024 → 0.0651（高偏场景下 SNIPS 反而更差）。
- 支撑论点：可写「IPS 有效性的曝光偏斜阈值」方法/结果素材。

### 2.2 曝光注入实验（injection.json）· `[已溯源]`

- 配置：`tau = 2.0`，`n_requests = 5000`，`slots = 5`，`w_base ∈ {0.0, 0.2, 0.4, 0.8, 1.0}`（5 档），**30 种子均值±std**。曝光只模拟一次，`L3=(1-w)·L2+w·truth` 逐 w_base 解析重算（rng_policy 见产物）。
- `injection_spearman`：**w=0.0 → 0.0；0.2 → 0.1929；0.4 → 0.4287；0.8 → 0.9147；1.0 → 0.9655**（±0.009~0.031）。形态为**严格单调上升**，无顶点回落（旧版 w=0.8 顶点 +0.8252 / w=1.0 回落 +0.7418 已证实为每档独立重抽曝光的采样噪声伪影，M2 修复后消失）。
- `injection_rel`（L3 相对误差）：w=0 时 0.0，w=1.0 时 −1.2457。
- `L3_spearman` 随 w_base 单调上升 0.0345 → 1.0（w=1.0 时恰为 1.0、std=0，端点跨种子确定性）；`L2_spearman` 恒为 0.0345（L2 不随 w_base 变化）。
- 支撑论点：可写「曝光注入强度对排序相关性的单调增益结构」结果素材（旧「峰值—回落」叙事已撤销）。

### 2.3 偏差传播实验（propagation.json）· `[已溯源]`

- 配置：`taus = [0, 0.5, 1, 2, 3]`，`w_base = 0.0`，`alpha = 5.0`，`n_requests = 5000`，`slots = 5`，**items=500、30 种子均值±std**（每 τ 以 `default_rng(seed+s)` 重置，CRN 口径，rng_policy 见产物）。
- 随 τ 增大（偏差累积层级加深）：`exposure_gini` 0.0794 → 0.6921；`exposure_kl` 0.0100 → 0.9716；
  `L2_spearman` 0.8665 → **−0.5054**（±0.01~0.03；τ=2 仍 +0.0345 已近随机，τ=3 转负，**零交叉发生在 τ≈2–3 之间**，越大越偏）；
  `L2_rel_err` 0.4112 → 1.2457 → 2.0133；`impr_min` 30.1 → 0.0、`impr_max` 72.5 → 1093.7。
- 机制 A（rel_err，水平）与机制 B（spearman，排序）随 τ 同步恶化。
- 支撑论点：可写「偏差在召回→排序→混排多级传播中的累积效应」方法/结果素材。

### 2.4 统计显著性（significance 字段）· `[已溯源]`

- 方法：**纯 numpy bootstrap**（百分位 CI + 重抽样 p 值，B=10000、固定种子 424242 逐字节可复现）——研究路径零重依赖，不引入 scipy（`src/bias/significance.py`）。
- 核心检验结果（30 种子传播/注入、250 种子 boundary，全部 p=0.0001 即 p<0.001）：
  - τ=3 排序反转：`L2_spearman` −0.5054，95% CI [−0.5123, −0.4988]；
  - τ=0 vs τ=3 同种子配对差：−1.3719，CI [−1.3790, −1.3652]（单侧 less）；
  - 注入 w=1.0 增益：+0.9655，CI [0.9547, 0.9767]；相邻档配对增量全部 p=0.0001；
  - boundary 边界档亏损：−0.0017，CI [−0.0021, −0.0013]；**无损档 gain≡0、p=1.0 正确不显著**（对照）。
- 支撑论点：「所有多种子论断均有统计检验背书」可写进可复现性/方法章节。

### 2.6 估计目标对照与 τ-sweep（历史补测，`6db28b3`）· `[已溯源]`

- **估计目标对照**（`estimand_check.json`，60 物品 / 400 请求历史口径，30 种子）：naive 对 `T_exp` 误差 0.0078~0.0100（≈1 个抽样标准误，纯噪声）——τ=3 时 naive=0.4025 vs `T_exp`=0.4028 仍贴合；SNIPS 始终贴 `T_pop`=0.2525（误差 0.0078→0.0169，τ=3 时 std 放大至 ±0.021，方差代价可见）；ESS 2000→400；τ=0 时两估计量重合（自洽）。支撑「IPS 换的是估计目标，不是修坏估计」论断。
- **去偏收益 τ-sweep**（`boundary_sweep.json`，60 物品、40 种子，N∈{1k,2k,5k,10k}）：gain 随 τ 单调上升，N=5000 时 τ=1→3 为 **+0.0468±0.0062 → +0.1395±0.0094**（历史记录 +0.07→+0.16 同向同量级，现已可复现）。
- 两个新产物均纳入零漂移门禁（repro.yml diff 列表扩至 5 个 JSON），CI run 38687162535 success。

### 2.7 propensity 估计误差与用户侧偏差（改进计划 #4/#5/#6，`5fc3933`）· `[已溯源]`

- **#4 估计误差**（`propensity_estimation.json`，60 物品/400 请求，30 种子）：日志频率估计 π̂ 替代闭式真 π，SNIPS 去偏误差变化不显著（delta≈0，p=0.87）→ **oracle 结论对估计误差稳健**；raw 估计的 ESS 预警偏保守（τ=2 误报 0.13、漏报 0，fail-safe 方向）。诚实注记：结论依赖日志规模（√N 收敛），边界阈值完整敏感性扫描未做。
- **#5/#6 用户侧偏差**（`userbias.json`，100 用户 × 60 物品，β 扫描，30 种子）：自选偏差让 naive 的 estimand 从 0.281 漂到 0.702（池化 CTR 虚高 2.5 倍）；**物品边际 propensity 去偏残余 +0.063→+0.222（全部 p<0.001），user-item 粒度正确去偏误差保持 0.004–0.037** → 用户侧偏差必须在 user-item 粒度建模。
- 门禁扩至 7 个 JSON，CI run 38713747031 success；`bias_report.md` §8 有完整叙事。

## 四、负结果 / 消融（H-3 ② ③）· 全部 `[已溯源]`

- **负结果（部分撤销）**：注入 `injection_spearman` 经 M2 统一 RNG 后呈**严格单调上升**（0.0→0.1929→0.4287→0.9147→0.9655），旧版「w=0.8 顶点 +0.8252 / w=1.0 回落 +0.7418」的伪顶点已被证为每档独立重抽曝光的**采样噪声伪影** → 该负结果**撤销**（非真实效应）。传播 `τ=3` 时 `L2_spearman` **转负**（−0.5054，零交叉 τ≈2–3）仍成立 → 「更深层级不单调更优」可作 Limitations。
- **消融数据**：boundary 6 档（ESS/N vs pi_ratio）、injection 5 档（w_base 扫描）、propagation 5 τ 档——均为现成消融，未只记赢家；S2 起传播/注入自带跨种子误差棒。
- naive vs SNIPS 对比：高偏场景 `snips_err`（0.0651）反高于 `naive_err`（0.0024），证明 SNIPS 在高偏下失效——可作方法讨论。
