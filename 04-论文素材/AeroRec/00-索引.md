## 二、已溯源技术事实（直接可进素材包）

来源基准：主仓库 `HEAD = de08111`；产物 `data/bias/{propagation,injection,boundary}.json`；文档 `docs/bias_report.md`。

### 2.1 去偏边界实验（boundary.json）· `[已溯源]`

- 配置：`n_records = 20000`，`tolerance_used = 0.001`，`n_seeds = 30`（边界多种子平均），`pi_min/pi_max` 扫描 6 档（`pi_ratio` 1 → 2×10⁶）。
- **核心结论**：`cross_ess_ratio = 0.3576`；ESS/N 降至约 **0.358** 以下时，去偏收益转负且超出噪声水平（容差 0.0010）——IPS 的方差代价超过纠偏收益。
- `naive_err` 各档恒为 `0.0021`；`snips_err` 随 `pi_ratio` 上升：0.0021 → 0.0616（高偏场景下 SNIPS 反而更差）。
- 支撑论点：可写「IPS 有效性的曝光偏斜阈值」方法/结果素材。

### 2.2 曝光注入实验（injection.json）· `[已溯源]`

- 配置：`tau = 2.0`，`n_requests = 600`，`slots = 5`，`w_base ∈ {0.0, 0.2, 0.4, 0.8, 1.0}`（5 档）。
- `injection_spearman`：**w=0.0 → 0.0；0.2 → 0.2006；0.4 → 0.4225；0.8 → +0.8252（顶点）；1.0 → +0.7418（回落）**。形态为**先升后落**，顶点在 `w_base = 0.8`。
- `injection_rel`（L3 相对误差）：w=0 时 0.0，w=1.0 时 −0.8677。
- `L3_spearman` 随 w_base 单调上升 0.8466 → 1.0（L3 接近真值）。
- 支撑论点：可写「曝光注入强度对排序相关性影响的单调—峰值结构」结果素材。

### 2.3 偏差传播实验（propagation.json）· `[已溯源]`

- 配置：`taus = [0, 0.5, 1, 2, 3]`，`w_base = 0.0`，`alpha = 5.0`，`n_requests = 600`，`slots = 5`，**单种子**。
- 随 τ 增大（偏差累积层级加深）：`exposure_gini` 0.0812 → 0.6211；`exposure_kl` 0.0103 → 0.6845；
  `L2_spearman` 0.8466 → **−0.4955**（排序相关性转负，越大越偏）；
  `L2_rel_err` 0.4022 → 1.0642 → 1.5216；`impr_max` 62 → 287。
- 机制 A（rel_err，水平）与机制 B（spearman，排序）随 τ 同步恶化。
- 支撑论点：可写「偏差在召回→排序→混排多级传播中的累积效应」方法/结果素材。

### 2.4 可复现性（repro.yml + run_bias_experiments.py）· `[已溯源]`

- 默认规模：`--items 60 / --requests 600 / --slots 5 / --seed 42`。
- `n_seeds = max(20, requests // 20)` = **30**（边界多种子）；传播 / 注入单种子。
- **零漂移门禁**：`git diff --exit-code` 逐字节校验 `data/bias/{propagation,injection,boundary}.json`（repro.yml:71-76）。
- CI：numpy 锁定 `2.3.5`；`bias-experiments` 仅 numpy（证明研究路径零重依赖）；在线侧断言不加载 torch；`pytest` 全量 + ruff + mypy。
- 支撑论点：可写「可复现工件声明」（论文强项，M4⑤）。

## 四、负结果 / 消融（H-3 ② ③）· 全部 `[已溯源]`

- **负结果**：注入 `w_base=0.8→1.0` 处 `injection_spearman` 自 +0.8252 **回落**至 +0.7418；传播 `τ=2/3` 时 `L2_spearman` **转负**（−0.0516 / −0.4955）。即「更大强度/更深层级不单调更优」——可作 Limitations。
- **消融数据**：boundary 6 档（ESS/N vs pi_ratio）、injection 5 档（w_base 扫描）、propagation 5 τ 档——均为现成消融，未只记赢家。
- na**ive vs SNIPS 对比**：高偏场景 `snips_err`（0.0616）反高于 `naive_err`（0.0021），证明 SNIPS 在高偏下失效——可作方法讨论。
