## 1. 引言 → `01-引言素材/`

- 问题定义：曝光偏差（popularity/position 两类，`injectors.py`）使观测日志偏离真实偏好；IPS/SNIPS/DR 是标准去偏工具，但其方差代价何时超过纠偏收益缺乏可操作判据。
- 动机（本项目独有，见 `docs/bias_report.md` §1）：真实日志只能*估计*偏差、不能*测量*；本项目 oracle 设定（真实 CTR 解析生成、propensity 闭式已知）使偏差可被精确测量。
- 基准与数据：Criteo 1M（AUC 0.7733）与 UCI Adult（AUC 0.9183）验证模型迁移性；去偏研究标准基准为 Coat / Open Bandit Dataset（MovieLens 不适合——未记录曝光策略与 propensity，见 `02-相关工作素材/`）。
- 出行域定位：合成出行域流量（`compute_true_ctr`），合成指标口径 AUC 0.8019 / 相对热门 +28.5%（诚实口径：不因真实数据验证而升级）。

## 3. 方法 → `03-方法素材/`

- 链路模型：L0 真值 → L1 召回（曝光份额尺度对齐）→ L2 排序（平滑 CTR，链路唯一可见信息）→ L3 混排（`(1−w)·L2+w·truth`）；机制 A（水平/稀疏收缩，τ=0 也存在）与机制 B（排序/曝光偏斜）必须分开度量——只看均值会被重标定抵消（`docs/bias_report.md` §2-3）。
- RNG 设计（决策台账）：CRN——每 (seed, τ) 以 `default_rng(seed+s)` 重置；注入实验单次模拟 + 解析扫描（旧版每 w_base 独立重抽产生的 w=0.4 伪回撤与 w=1.0 伪回落已证伪并撤销，commit `1d6ab88`）。
- 显著性方法：numpy-only bootstrap（百分位 CI + 重抽样 p 值，B=10000，固定种子 424242；p 最小可达 1/(B+1)=0.0001 应读作 p<0.001）；不引入 scipy 的理由：研究路径零重依赖是 CI 强制约束（`src/bias/significance.py` docstring）。
- 决策台账全表见 `00-索引.md` 三。

## 5. 结果 → `05-结果素材/`

核心数字（全部带跨种子误差棒与显著性）：

1. **排序反转**：`L2_spearman` +0.8665 → −0.5054（±0.01~0.03），零交叉 τ≈2–3；τ=3 反转 p<0.001（CI [−0.5123, −0.4988]）；τ=0→3 配对下降 −1.3719，p<0.001。
2. **二次注入单调**：injection_spearman 0 → 0.9655，相邻档增量全部 p<0.001；w=1.0 端点 L3≡truth（自检）。
3. **有效边界**：ESS/N ≈ 0.358（0.3576→0.3579 对规模稳健）；边界档亏损 p<0.001，无损档 p=1.0 正确不显著；naive_err 恒 0.0024。
4. **估计目标分离**：naive 贴 T_exp 至 0.01 内（τ=3 时 0.4025 vs 0.4028）；SNIPS 贴 T_pop=0.2525；ESS 2000→400。
5. **τ-sweep**：gain 随 τ 单调升至 +0.1395±0.0094（N=5000）。
6. **负结果 / 撤销记录**：旧「w=0.8 顶点 +0.8252 / w=1.0 回落 +0.7418」为采样噪声伪影，已撤销（`1d6ab88`）——撤销过程本身可写进方法或结果（测量误差的活案例）。
