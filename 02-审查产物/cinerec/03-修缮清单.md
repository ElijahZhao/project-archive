## 🟠 中等（建议尽快修）

### M1 · CORS 允许源硬编码为 localhost
- **位置**：[api/main.py:52](file:///workspace/cinerec/api/main.py#L52)
- **问题**：`allow_origins=["http://localhost:8000", ...]` 写死本地地址，未读取环境变量。
- **风险影响**：部署到 Render 后，任何非 localhost 的跨域客户端（独立前端、调试页、第三方集成）请求会被浏览器拦截。同源访问（Render 自身托管的页面）不受影响，故线上主流程不会崩，但**限制了可扩展性且属配置缺陷**。
- **改法**：改为从环境读取，保留本地默认：
  ```python
  import os
  _origins = os.environ.get("ALLOWED_ORIGINS", "http://localhost:8000,http://localhost:3000,http://127.0.0.1:8000")
  allow_origins=[o.strip() for o in _origins.split(",") if o.strip()],
  ```
  并在 `.env.example` 增加 `ALLOWED_ORIGINS=` 说明。属"修配置"，不扩功能。
