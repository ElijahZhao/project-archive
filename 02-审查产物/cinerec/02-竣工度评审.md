## 1. 竣工判定标准（先立标准，再核验）

**【事实】** 采用软件产品质量通用模型 **ISO/IEC 25010**（2011/2023 版产品质模型）的八个特性维度，并叠加「可交付项目」常用的 **Definition of Done（DoD）** 维度（构建/部署/文档/许可）。
> 来源说明：ISO/IEC 25010 是国际标准软件质量模型（功能性 functional suitability、性能 efficiency、兼容性、易用性、可靠性 reliability、安全性 security、可维护性 maintainability、可移植性 portability）；DoD 为敏捷工程通用实践。**本次为基于既有标准的核验框架，未联网抓取原文 URL。**

| # | 维度 | 判定要点 |
|---|---|---|
| 1 | 功能完整性 | 宣称的功能是否都存在且可用 |
| 2 | 测试覆盖 | 有测试、能通过、覆盖关键路径 |
| 3 | 文档 | README/ADR/注释与实现一致、可复现 |
| 4 | 构建与部署 | 可构建、可部署、有健康检查 |

| 8 | 可维护性 | 单一真相源、可读性、命名 |

**【判断】** 宣称的"6 级算法阶梯 + 可解释 + 双语 + 双模式部署"在代码层均有对应实现。**唯一保留意见**：`lite` 模式依赖预计算缓存，新用户会回退到热门推荐（已明确标注，非缺陷）。

### 维度 6 · 异常处理 — **部分达成**
**【事实】已处理的**：`AlgorithmUnavailable`（`registry.py:25,53,73-76`）区分"未知算法"与"当前部署不可用"；lite 模式无缓存条目返回显式文案而非报错（ADR 0001）；`_verify_password` 处理损坏哈希（`auth.py:54-55`）；`_int_env` 容错（`config.py:34-39`）；SPA 路径穿越返回 None（`main.py:82`）。
**【事实】薄弱处**：这些失败分支多数**无测试**（`recommend.py` 56%、`registry.py` 60%）。`dry-run` 也未见对 DB 锁/SQLite `OperationalError` 的专门处理（压测报告自述高尾延迟源于 SQLite 写竞争，`reports/loadtest.md:69-74`）。
**【判断】** 代码里"考虑了"异常，但"验证了"异常不足。部分达成。

### 维度 7 · 安全 — **部分达成**
**【事实】做得好的**：无硬编码密钥；PBKDF2 200k + 随机盐；HMAC 签名令牌 + TTL；SQL 全参数化；路径穿越防护有单测；容器非 root。
**【事实】短板**：
- CORS 硬编码 localhost（`api/main.py:52`）——部署后跨域不可用（升高为配置缺陷）。
- 令牌无吊销、单共享密钥（`auth.py:8-9` **已在文档中诚实声明**，非隐瞒）。
- 保留 legacy 无盐 SHA256 校验路径（`auth.py:57-59`）——迁移期兼容，属可接受但需知悉。
**【判断】** 作为"作品集部署"的自我定位是诚实的，但按"可交付项目"标准，安全为部分达成。

### 维度 8 · 可维护性 — **已达成**
**【事实】** 算法集合与加载方式唯一来源（`registry.py` 头注释明确）；双模式差异集中在 `config.py`；ADR 记录关键取舍；模块化目录清晰；`svd_als.py` 命名与实现不符，但 **ADR 0003 与 README 均明确写为 truncated SVD**，风险被文档抵消。
**【判断】** 达成（命名债为可接受的历史包袱）。

### 维度 9 · 许可与合规 — **部分达成**
**【事实】** `LICENSE` 为 MIT，与 README 一致；MovieLens 100K 为公开学术数据集（GroupLens 允许研究用途）。
**【判断】** 合规风险点：**TMDB**。`data/enrich_tmdb.py` 使用 TMDB API 富化海报/剧情，README 未见对 TMDB 的署名/免责声明。TMDB API 条款通常要求 "This product uses the TMDB API but is not endorsed…" 类署名。**【判断，未联网核实条款原文】** → 标为部分达成/待核实。

## 5. 唱反调：三个"看起来完成但没完成"的假象

1. **"有测试" ≠ "测了关键路径"**：62 个测试全绿很漂亮，但覆盖率表揭示**核心创新模型多模态 NCF 仅 45%、评测主流程 0%**。绿灯主要来自 API/工具层。
2. **"文档很好" ≠ "文档最新"**：README 的数字（评测表）非常准确且诚实，但**截图、回退文案、ROADMAP 状态行**三处时效性内容已过期——评审者第一眼看的恰是截图。
3. **"安全做了" ≠ "部署可用"**：认证实现比多数作品集项目扎实（PBKDF2+HMAC），但 **CORS 仍锁死 localhost**，一旦有非同类源客户端就会撞墙——功能与安全的交界处最容易漏。
